## Description
The User Blog is an engaging platform where users can register and share their thoughts through posts accompanied by images. Designed for simplicity, it allows users to easily create and publish content.
Administrators have the authority to manage all posts, ensuring quality and relevance. Built using Node.js, EJS, and Knex.js, this project combines a robust backend with a user-friendly interface.

## Instructions to Run the Application
### 1. Cloning the Repository
Make sure you have a Git client installed on your computer. You can either download the project using the **"Code"** button on GitHub or use the following command:
```bash
git clone https://github.com/Odrozkeskal/project_blog
cd project_blog
```
### 2. Installing Dependencies
```bash
npm install
```
### 3. Starting the Application
After installing the dependencies, start the application using:
```bash
npm start
```
 ### 4. Opening the Application
In your browser, navigate to: http://localhost:3000/
You should see your application.
